IPSL-AID Notice
===============

This project includes code contributed by Klima Consulting.

The SAL (Structure-Amplitude-Location) diagnostic implementation and
associated plotting routines in ``src/IPSL_AID/diagnostics.py`` were
developed by Klima Consulting.

The SAL-related code includes routines for:

- SAL score computation;
- SAL object identification and analysis;
- temporal SAL diagnostics;
- SAL diagnostic plotting.
